# Code of Conduct

We want tinytools to be a friendly place to contribute, in Italian or English.

- Be respectful and assume good intent.
- Give feedback on the code, not on the person.
- No harassment, discrimination or personal attacks.
- Maintainers can remove comments, issues or pull requests that break these rules.

To report a problem, use a GitHub Security Advisory or contact the maintainer through the profile of the repository owner.
